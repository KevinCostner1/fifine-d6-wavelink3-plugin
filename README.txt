Wave Link 3 Universal - v1.0.0

Plugin comunitário para FIFINE Control Deck / AmpliGame D6 que integra o Elgato Wave Link 3.

Desenvolvido por Costner
Twitch: https://twitch.tv/costnergg

RECURSOS
- Mute / Unmute configurável
- Volume + e Volume - em passos de 10%
- Repetição ao segurar Volume + / -
- Entrada / canal (fonte)
- Canal em um mix
- Mix / saída do mix
- Entrada física e saída física quando expostas pela API
- Atualização de volume e estado em tempo real
- Configuração individual de cada botão
- Interface multilíngue: Português (Brasil), English e Español, com detecção automática do idioma do sistema
- Percentual de volume exibido no MIC e nos controles de status
- Campo de seleção de ícone removido; cada ação usa seu próprio ícone automaticamente

REQUISITOS
- Windows 10 ou superior
- FIFINE Control Deck / AmpliGame D6
- Elgato Wave Link 3 instalado e em execução

INSTALAÇÃO
1. Feche o FIFINE Control Deck se estiver aberto.
2. Execute Instalar-WaveLink3.bat como administrador.
3. Abra o FIFINE Control Deck.
4. Procure a categoria "Wave Link 3 Universal".

LICENÇA / DISTRIBUIÇÃO
Este é um projeto comunitário e independente da FIFINE e da Elgato.

Localization: automatic based on the Control Deck application language. Supported: Portuguese (Brazil), English, Spanish, Simplified Chinese and Traditional Chinese.
Rapid input: actions are sent without waiting for the previous request, with optimistic local state to avoid dropped rapid presses.
